# まちづくりシミュレーション

初代の都市育成シミュレーションゲームにインスパイアされた、ブラウザで遊べるオリジナルの街づくりゲームです。
スマートフォンのブラウザでプレイでき、セーブして続きから再開できます。

## 遊び方

1. ⚡ **発電所**を建てる(電気がないと町は育ちません)
2. 🛣️ **道路**を引く(区画は道路の近くでないと発展しません)
3. 🏠 **住宅地**・🏬 **商業地**・🏭 **工業地**の区画を指定する
4. 🗼 **送電線**で発電所と区画をつなぐ(区画同士が隣接していれば電気は伝わります)
5. 画面上部の **住・商・工** バー(需要メーター)が伸びている区画を増やす
6. 🚓 警察署・🚒 消防署・🌳 公園で町の環境を整える(消防署は火事を防ぎます)
7. ☰ メニューから**税率**を調整して財政と人口のバランスを取る

### 操作方法(スマホ)

- ✋ **移動ツール**:ドラッグでスクロール、タップでタイル情報表示
- 2本指で**ピンチズーム**
- 建設ツールを選んでタップ/ドラッグで建設(道路や区画はドラッグで連続建設できます)
- PCの場合はマウスドラッグ+ホイールズームでも操作できます

### セーブ機能

- ☰ メニュー → 💾 セーブ でいつでも保存できます
- 毎年1月とブラウザを閉じる時に**自動セーブ**されます
- 次回アクセス時にタイトル画面の「▶ つづきから」で再開できます
- セーブデータはブラウザの localStorage に保存されます(同じ端末・同じブラウザでアクセスしてください)

## ゲームシステム

- **電力**:発電所から送電線・区画・施設を伝って電気が流れます。電気が来ていない区画は ⚡ が点滅し、発展しません。発電所1基で送電できる範囲には限りがあります
- **需要(RCI)**:仕事(商業・工業)が増えると住民が増え、住民が増えると商業・工業の需要が伸びます
- **公害**:工業地帯と発電所は周囲に公害をまき散らし、住宅の発展を妨げます
- **火災**:発展した町ではまれに火事が起きます。消防署のカバー範囲内なら延焼を防げます。焼け跡(がれき)は 🚜 整地してから建て直しましょう
- **財政**:毎月、人口と雇用に応じた税収が入り、道路・施設の維持費が引かれます
- **マイルストーン**:人口 100(村)→ 500(町)→ 2000(市)→ 10000(大都市)→ 50000(巨大都市)

## 動かし方

ビルド不要の静的サイトです(HTML / CSS / JavaScript のみ)。

### ローカルで試す

```bash
# リポジトリ直下で
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

### スマホで遊べるように公開する(GitHub Pages)

1. GitHub リポジトリの **Settings → Pages** を開く
2. Source を「Deploy from a branch」、Branch を公開したいブランチ(`main` など)の `/ (root)` に設定
3. 表示された URL にスマホのブラウザでアクセス

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 画面構成(HUD・ツールバー・メニュー・タイトル画面) |
| `style.css` | スマホ向けUIスタイル |
| `game.js` | ゲームロジック(マップ生成・シミュレーション・描画・入力・セーブ) |
